# Sequelize Node.js CRUD API

A simple CRUD API using:
- Node.js
- Express.js
- Sequelize ORM
- MySQL

## Installation

```bash
npm install
```

## Run Project

```bash
npm start
```

## API Endpoints

### Create User
POST /users

### Get Users
GET /users

### Update User
PUT /users/:id

### Delete User
DELETE /users/:id
